§3统计内核

六个公式构成全部推断链；红线紧贴公式，因为它们必须被一起读到。

e_a(x)  →  wᵢ  →  μ̂ₐ  →  Σ̂  →  d̂ᵢⱼ  →  [Lᵢ, Uᵢ]

① 倾向得分

e_a(x) = P(T=a | X=x), Σₐ e_a(x) = 1

联合多分类 GBM；cross_fit → OOF 概率

e=0 直接报错；裁剪默认关闭

② Hájek IPTW

wᵢ = 1/ê_{Tᵢ}(Xᵢ) μ̂ₐ = Σ1{Tᵢ=a}wᵢYᵢ / Σ1{Tᵢ=a}wᵢ

所有臂在同一目标总体——排名才可比

禁止 HT / Hájek 混合算法

③ 有效样本量

ESSₐ = (Σᵢ wᵢₐ)² / Σᵢ wᵢₐ²

少数极端权重主宰估计 → 门控降级

低 ESS 触发 warning

④ 联合 Bootstrap 协方差

Σ̂ = np.cov(draws, rowvar=False, ddof=1)

共享行重抽样：臂间相关进入差值 SE

绝不再除以 n；非 PSD → 报错

⑤ Bonferroni 同时区间

d̂ᵢⱼ ± z₁₋α/(2M)·√(Σᵢᵢ+Σⱼⱼ−2Σᵢⱼ) M = K(K−1)/2

区间不跨 0 才确认方向；K=2 退化

单项 CI 重叠 ≠ 显著性检验

⑥ 保守排名置信集

[Lᵢ, Uᵢ] = [1 + Bᵢ, K − Wᵢ]

并列共享名次并标记 point_tie

点第一的频次 ≠ 最优概率

rare_treatmentwarningvalidation稀有臂，交叉拟合折与 Bootstrap 重抽样风险高

§5诚实红线

这个项目一半的性格在"拒绝做什么"。八条红线写在代码、文档、报告与测试里。

点估计排序≠确立的排名
排名只来自同时区间的覆盖性质
inconclusive≠相等的证据
决策词表里没有 equal / tie
排第一的频次≠最优概率
Bootstrap 频次不携带概率语义
单项 CI 重叠≠显著性检验
两两结论只由 Bonferroni 区间给出
AUC / 准确率≠因果证据
相关屏幕是平衡 · 重叠 · 稳定性
标签字母序≠并列打破依据
并列共享名次并显式标记
静默裁剪倾向得分≠允许
默认关闭；显式配置须报告比例
修补非 PSD 协方差≠允许
报错不修补；门槛不过则阻断并披露
