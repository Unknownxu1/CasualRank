因果排名CausalRank — architecture

面向观测数据的多 Treatment 因果结局估计、联合不确定性量化与统计上可辩护的排名的端到端 Python 框架。本页依据源码与 docs/ 整理，介绍 v0.4.0 的数据流、模块分工、统计内核、质量门控与工程验证。

§1端到端数据流

一条主链从原始 DataFrame 走到排名置信集；三处旁路分别负责经验诊断、联合协方差与失败披露。每一步的预处理都只在训练折 / 重抽样内拟合，杜绝泄露。

01
输入契约
validation.py

schema、标签规范序、dtype 归一化、缺失与重复行检查；不合规立即拒绝而非静默删除。

02
多分类倾向得分
estimators/propensity.py

联合多分类 GBM（非 one-vs-rest），插补 / 独热编码包在 Pipeline 内；可选 5 折 OOF 交叉拟合。

e_a(x) = P(T=a | X=x)
03
Hájek IPTW
estimators/iptw.py

组内归一化加权均值，所有臂在同一目标总体上估计；HT 形式仅作内部数值核对。

wᵢ = 1/ê_{Tᵢ}(Xᵢ)
04
联合 Bootstrap
inference/bootstrap.py

每轮共享行重抽样并重拟合全部协议，B×K draws 求协方差；逐轮种子派生，与执行顺序和 n_jobs 无关。

Σ̂ = np.cov(draws, ddof=1)
05
同时两两区间
inference/pairwise.py

差值标准误带入联合协方差中的臂间相关性，Bonferroni 校正 M=K(K−1)/2 对。

d̂ᵢⱼ ± z₁₋α/(2M) · SE
06
排名置信集
inference/ranking.py

由可确认优劣关系构造保守区间；点估计并列共享名次并显式标记。

[1+Bᵢ, K−Wᵢ]
07
结果对象
results.py

估计表、协方差、两两表、排名表、结构化警告与元数据；数值 API 不依赖绘图库。

08
静态报告
visualization/report.py

自包含 HTML 与内联 SVG 图；渲染器只读结果对象，不重算任何统计量。

result.to_html(path)
质量诊断（旁路）
diagnostics/

权重分布与 ESS、共同支持、加权前后 SMD，汇成 pass / caution / fail 门控。

推断阻断（旁路）
bootstrap_min_success_rate = 0.9

成功率或成功轮数不过门槛时不给 Σ，附失败原因清单——宁可不推断，不给可疑协方差。

合成验证（旁路）
simulation/

8 个已知真值的 DGP 场景与 Monte Carlo 基准，为每个统计结论提供覆盖率证据。

§3统计内核

六个公式构成全部推断链。每个面板给出公式、含义与数值边界；红线以红字紧随公式，因为它们必须和统计量一起被读到。

倾向得分预测模型，不是因果方法

e_a(x) = P(T = a | X = x),   Σₐ e_a(x) = 1

联合多分类 GBM；cross_fit=m 产生 out-of-fold 概率，消除"同一份数据既拟合又评估"的过拟合权重；默认超参在已知真值倾向面上调定。

裁剪默认关闭；显式配置时只做下界且报告比例；e=0 属 positivity 违背，直接报错。

Hájek IPTW主估计器 · 同一目标总体

wᵢ = 1 / ê_{Tᵢ}(Xᵢ)
μ̂ₐ = Σ 1{Tᵢ=a} wᵢYᵢ / Σ 1{Tᵢ=a} wᵢ

二元结局下必落在 [0,1]；组内权重同乘常数估计不变。原始组均值比较的是不同人群，这里的每个 μ̂ 都在同一目标总体上，排名才可比。

禁止"组内归一化权重再除以 n"的混合算法——HT 与 Hájek 两个函数独立实现、独立手算测试。

有效样本量权重把信息集中到多少条观测

ESSₐ = (Σᵢ wᵢₐ)² / Σᵢ wᵢₐ²,   wᵢₐ = 1{Tᵢ=a} wᵢ

ESS 崩塌意味着少数极端权重主宰该臂的估计；ESS 与 ESS 比是门控降级的直接触发量之一。

联合 Bootstrap 协方差每轮重拟合全部协议

Σ̂ = np.cov(draws, rowvar=False, ddof=1)

同一行索引向量服务全部 Treatment，臂间相关性因此被带入每个差值标准误；逐轮种子由 SeedSequence(base).spawn(B) 派生，同种子逐位可复现。

每行已是完整估计量，绝不再除以 n；非 PSD 明确报错，不做数值修补。

Bonferroni 同时区间可确认的优劣关系

d̂ᵢⱼ ± z₁₋α/(2M) · √(Σ̂ᵢᵢ + Σ̂ⱼⱼ − 2Σ̂ᵢⱼ),   M = K(K−1)/2

仅当区间整体位于 0 的一侧才确认方向；K=2 时退化为常规两方案比较（已测）。

单项 CI 重叠不能代替显著性检验；inconclusive 不是相等的证据。

保守排名置信集同时覆盖意义下的名次区间

[Lᵢ, Uᵢ] = [1 + Bᵢ,  K − Wᵢ]

Bᵢ / Wᵢ 为可确认优于 / 劣于臂 i 的臂数；点估计并列共享名次并以 point_tie 标记，绝不按标签字母序打破。

Bootstrap 中点排名第一的频次不是最优概率；真实效果并列时区间变宽是正确输出。

§4质量门控

17 个结构化警告码按最高级别汇成一个门控。警告是机器可读对象，不是打印字符串——门控可以被测试断言。

pass

无 warning / critical 级发现。只是本样本的经验陈述，不验证任何识别假设。

caution

至少一条警告。先读警告，再解释任何调整均值或排名。

fail

存在 critical 发现。估计仍返回以保透明，但不得包装成可靠因果排名。

警告码级别来源触发条件
label_dtype_castinfovalidation标签被安全转换类型（int/str/bool/float 整数值）
missing_covariatesinfovalidation协变量存在缺失，将在训练折内插补
high_cardinality_categoricalwarningvalidation类别基数超过 max_category_cardinality（默认 25）
small_groupwarningvalidation某臂样本数低于 min_group_n（默认 30）
rare_treatmentwarningvalidation稀有臂，交叉拟合折与 Bootstrap 重抽样风险高
duplicate_rowswarningvalidation完全重复行——iid 抽样假设存疑，聚类结构需 cluster bootstrap
low_esswarningweightsESS < min_ess（30）或 ESS 比 < 0.2
extreme_weightwarningweights单条权重占该臂总权重 > 10%
propensity_clippedwarningweights显式裁剪实际发生——必须与任何结果一起披露
no_common_supportcriticaloverlap部分目标样本上 e_a(X)=0：该臂均值在那里不可识别
weak_common_supportwarningoverlap目标样本低概率占比 > 5%——population_mean 依赖外推
low_propensitywarningoverlap实际处理倾向 < 0.01，或近确定性分配占比过高
degenerate_smdwarningbalance组内方差为零，SMD 按约定取 0 或 ∞
residual_imbalancewarningbalance加权后 max|SMD| > 0.1——筛查惯例，不是无偏保证
severe_imbalancecriticalbalance加权后 max|SMD| > 0.25——调整均值可能仍被混杂
bootstrap_failureswarningbootstrap存在失败轮（低于门槛时升为 critical），逐轮记录原因
bootstrap_inference_blockedcriticalbootstrap成功率 < 90% 或成功轮 < 30：推断阻断，不返回 Σ

§5诚实红线

这个项目一半的性格在"拒绝做什么"。以下八条写在代码、文档、报告与测试里，任何输出形态都不得越过。

  • 点估计排序 ≠ 统计上确立的排名排名结论只能来自同时区间的覆盖性质，不能来自 μ̂ 的大小顺序。
  • inconclusive ≠ 相等的证据决策词表里没有 equal/tie；"差异不显著"与"效果相等"是两个命题。
  • 点排名第一的频次 ≠ 最优概率Bootstrap 里某臂排第一的次数不携带概率语义，报告与文档都不这样呈现。
  • 单项 CI 重叠 ≠ 显著性检验两两结论只能由 Bonferroni 同时区间给出。
  • AUC / 准确率 ≠ 因果有效性证据相关屏幕是平衡、重叠与稳定性；模型拟合指标从不作为质量判据输出。
  • 并列绝不按标签字母序打破点估计并列共享名次并显式标记，真并列时区间变宽而非强选赢家。
  • 倾向裁剪不静默发生默认关闭；显式配置时报告比例；e=0 直接失败而不是被裁剪掩盖。
  • 协方差非 PSD → 报错不做特征值修补、不加 ridge 掩盖；推断门槛不过则阻断并附原因清单。

§6演进路线

五个阶段按次序实施，每一阶段先通过统计验收再进下一阶段；当前停在 Phase 4。

Phase 0
骨架与契约

包结构、配置校验、真值可复现的 DGP、README 红线声明。

Phase 1
估计链路

GBM 倾向 + Hájek IPTW + 权重 / 重叠 / 平衡诊断与质量门控。首个可用里程碑。

Phase 2
联合推断

重拟合 Bootstrap 协方差、SE / CI、失败披露与推断阻断、SE 校准模拟。

Phase 3
排名推断

Bonferroni 同时区间、可确认优劣、[1+Bᵢ, K−Wᵢ]、并列约定、覆盖率基准。MVP。

Phase 4 · 当前
分发与可视化

静态 HTML 报告、5 种 SVG 图、CSV→HTML 示例、PyPI Trusted Publishing 发布链路。

之后（规格 §6 明确列后、不提前实现）

max-T / stepdown 排名推断 · AIPW / 重叠加权（新 estimand）· 灵敏度分析 · 影响函数 / sandwich 对照 · cluster bootstrap · 近似最优集合与 MCB。半成品统计量被误用的风险大于缺功能的风险，因此每一项都以独立验证为前置。
